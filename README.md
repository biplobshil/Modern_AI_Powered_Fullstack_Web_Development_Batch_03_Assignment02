# 🌾 বটিয়াঘাটার ভাটেল চাল — সিঙ্গেল প্রোডাক্ট ল্যান্ডিং পেজ

খুলনার বটিয়াঘাটার ঐতিহ্যবাহী সুগন্ধি আমন ধানের **ভাটেল চাল** (স্থানীয়ভাবে ভাইটেল বা রানী স্যালুট নামে পরিচিত) বিক্রির জন্য একটি সিঙ্গেল ল্যান্ডিং পেজ। পেজটার একটাই কাজ: ভিজিটরকে অর্ডার করানো।

**🔗 লাইভ সাইট:** https://biplobshil.github.io/Modern_AI_Powered_Fullstack_Web_Development_Batch_03_Assignment02/

> Modern AI Powered Fullstack Web Development (Batch 03) — Assignment 02: অর্গানিক প্রোডাক্টের সিঙ্গেল ল্যান্ডিং পেজ

## প্রোডাক্ট সম্পর্কে

- **কী:** ভাটেল চাল, সুগন্ধি আমন ধান থেকে তৈরি
- **কোথা থেকে:** খুলনার বটিয়াঘাটা, দাকোপ ও ডুমুরিয়া অঞ্চল
- **বিশেষত্ব:** রান্নার সময় প্রাকৃতিক সুগন্ধ ছড়ায়; পলিশ ও মিশ্রণমুক্ত
- **ব্যবহার:** সাদা ভাত, পোলাও, বিরিয়ানি, পায়েস, ফিরনি, জাউ ভাত, পিঠার চালের গুঁড়া

## পেজের সেকশন

1. **Hero** — প্রোডাক্টের বড় ছবি, হেডলাইন আর অর্ডার বাটন
2. **কেন ভাটেল** — ছয়টি মূল সুবিধা
3. **উৎস** — বটিয়াঘাটার মাঠ থেকে প্যাকেট পর্যন্ত ধাপগুলো
4. **কী রাঁধবেন** — ব্যবহারের তালিকা
5. **তুলনা** — বাজারের সাধারণ চাল বনাম ভাটেল
6. **খাঁটি চেনার উপায়** — ঘ্রাণ, দানা, ধোয়া ও রান্নার পরীক্ষা + ফেরতের প্রতিশ্রুতি
7. **প্যাকেজ ও দাম** — ৫ / ১০ / ২৫ কেজি, ডেলিভারি চার্জ
8. **কাস্টমার রিভিউ**
9. **FAQ**
10. **অর্ডার ফর্ম** — মোট দাম নিজে থেকে হিসাব হয়, অর্ডার WhatsApp-এ চলে যায়

## বৈশিষ্ট্য

- 📱 মোবাইল-ফ্রেন্ডলি রেসপন্সিভ ডিজাইন, মোবাইলে নিচে সবসময় "অর্ডার করুন" বাটন
- 🎨 প্রোডাক্টের সাথে মিলিয়ে রঙ: ধানক্ষেতের সবুজ আর ধানের সোনালি
- 🧮 প্যাকেজ, পরিমাণ ও এলাকা বদলালে মোট দাম সাথে সাথে আপডেট হয়
- 💬 ব্যাকএন্ড ছাড়াই অর্ডার: ফর্ম জমা দিলে অর্ডারের বিবরণসহ WhatsApp খুলে যায়
- ⚡ কোনো ফ্রেমওয়ার্ক নেই, শুধু HTML, CSS আর সামান্য JavaScript
